# Aditya Rastogi Portfolio

Modern React/Vite portfolio starter built for developer job applications.

## Run locally

```bash
npm install
npm run dev
```

## Important things to edit

Open `src/App.jsx` and update the `contact` object:
- phone
- email
- WhatsApp number
- address
- LinkedIn
- GitHub

Also update:
- About text
- Skill percentages
- Projects
- Project demo/source links
- Education/training details

## Resume

Replace `public/Aditya-Rastogi-Resume.pdf` with your real resume PDF using the same file name.

## Deploy

You can deploy this Vite project on Vercel, Netlify, Cloudflare Pages or GitHub Pages.
